Общие принципы
- Сортировка по клику на заголовок, сохранение состояния фильтров в query
- Массовые действия с подтверждением и оптимистичным обновлением
- Состояния: загрузка (скелетоны), пусто, ошибка (retry)
- Иерархические данные (структура курса, попытки экзаменов, каталог) — рекурсивные
  многоуровневые таблицы с раскрытием строк, а не плоские списки с отступом (`RecursiveTable`)
- Единый стиль попапов: диалоги только через ConfirmDialog/AppDialog, тосты только через useToast
  (конвенция — design-redesign-plan, Фаза 1.5.2)

Курсы (Courses)
- Таблица: id:number(sort), title:string(sort/filter), category:string(filter), aircraft:string(filter), status:enum(sort/filter), lessons:number, updated_at:datetime(sort)
- Действия строки: Просмотр, Редактировать, Публиковать/Снять, Удалить
- Массовые: Публиковать, Снять, Удалить
- Форма: title(required, max:255), description(max:4000), category_id(required), aircraft_id(optional), status(enum: draft|published), files[]
- Состояния:
  - загрузка: скелетоны строк 5–10 шт.
  - пусто: «Нет курсов», кнопка «Создать курс»
  - ошибка: алерт с сообщением, кнопка «Повторить»
  - пагинация: серверная, meta.pagination
- Валидация: title required, max 255; category_id required; status in [draft,published]

Занятия (Lessons)
- Таблица: id, course:title(link), chapter, duration, visible:bool
- Действия: Редактировать, Скрыть/Показать, Удалить

Пользователи (Users)
- Таблица: id, fio, role, group, last_login
- Действия: Сброс пароля, Изменить роль/права, Удалить
- Форма: fio(required), role(required enum), password(required on create, min:6), group_id
- Состояния:
  - загрузка: скелетоны
  - пусто: «Нет пользователей», кнопка «Добавить» (для админов)
  - ошибка: алерт, retry
  - пагинация: серверная, meta.pagination
- Валидация: fio required; role in [Администратор,Инструктор,Обучаемый]; password min 6

Группы/Зачисления
- Таблица групп: id, name, members
- Таблица зачислений: id, group, course, status
- Действия: Зачислить/Отчислить, Импорт CSV

Отчеты
- Таблица: Пользователь, Курс, Прогресс, Результат теста, Дата

Диалоги подтверждения
- Удалить: требует ввод «DELETE» для перманентного
- Публиковать/Снять: чекбокс уведомления пользователей

## Типографика и токены

- Базовый кегль: 15px; шкала: `--fs-sm: 12px`, `--fs-base: 15px`, `--fs-lg: 18px`, `--fs-xl: 24px`, `--fs-2xl: 32px`, `--fs-3xl: 38px`, `--fs-4xl: 46px`
- Семейт шрифта: `Inter`, фолбэк — системный стек
- Цвета токенов: `--c-primary: #1a5fb4`, `--c-accent: #0d9488`, `--c-surface: #f8f9fa`, `--c-bg: #ffffff`
- Для dark-темы: `--c-surface: #0e1116`, `--c-bg: #1a1f26`

## Состояния экранов (4 состояния каждого экрана)

Каждый экран должен реализовывать 4 состояния:
1. **Loading** — `AppSkeleton` с соответствующим variant (table/cards/form/text), замена спиннеров
2. **Empty** — `EmptyState` с иллюстрацией и action-кнопкой («Создать курс», «Добавить пользователя» и т.д.)
3. **Error** — `v-alert` с сообщением и кнопкой «Повторить», скролл к первому полю с ошибкой
4. **Success** — нормальный контент с оптимистичным обновлением

## Стили кнопок и полей

- Кнопки: `--radius-pill: 999px` для CTA, `--radius-lg: 14px` для карточек, `--radius-md: 8px` для полей
- Hover состояния: `transition: background var(--dur-fast) var(--ease), color var(--dur-fast) var(--ease)`
- Focus-visible: `2px solid var(--c-primary)` или `2px dotted var(--c-text-muted)` при `prefers-reduced-motion`
- Инлайн стили `style="width:"` — zakazano, используйте `--w-form-narrow: 480`, `--w-form-base: 720`, `--w-form-wide: 1080`
- Hex-цвета — только в `tokens.css`, вне — lint error
- `elevation-12` — zakazano, используйте `--shadow-1` через `--shadow-5`

## Утилиты общего назначения (`resources/css/app.css`)

`u-`-классы живут в `app.css`, а не в страницах: повторяющаяся мелочь в трёх
местах — это не «мелочь», а отсутствующая утилита.

| Класс | Для чего |
|---|---|
| `.u-truncate` | Обрезка одной строкой с многоточием |
| `.u-clamp-group` | `.u-truncate` плюс ширина в `ch` для текста в ячейке таблицы |
| `.u-mono` | Моноширинный текст с разрядкой: секреты 2FA, где важно отличать `0` от `O` |
| `.u-sr-only` | Текст только для скринридера |
| `.u-badge` | Небольшая метка состояния |

## Правило про scoped

`<style>` без `scoped` — исключение. Файл бывает подключён идеально, а его
unscoped-блок при этом перекрашивает чужие страницы — и `tools/reachability.py`
этого не видит, он ищет только недостижимые файлы. Найденные утечки и что с
ними сделано — `docs/cleanup-manifest.md`.

Оправдан unscoped-блок ровно один: `.highlighted` в `CourseManifest.vue` —
класс приходит из HTML, который отдаёт сервер для результатов поиска по
материалу, и правило обязано быть видно внутри того документа.

Классы дочерних компонентов внутри `scoped`-блока требуют `:deep()`.
